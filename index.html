About

Bridging the shop floor and software

I work where programming and production meet. My days go to turning customer drawings and piece lists into machine-ready programs, and to finding the repetitive steps in that process that a small tool can take over.

I came to software through manufacturing, so the tools I build fit how a shop actually runs: quick to learn, built around the files people already use, and aimed at fewer mistakes and less scrap.

I'm studying computer science and engineering at Stark State College, with an artificial intelligence certificate alongside it. I'm looking for roles in technology and manufacturing where I can keep doing both.

Projects

Tools I've built

Panel Out Automation

DESKTOP APP

A desktop tool that turns a job's saw piece list into a finished panel layout. It reads the piece-list workbook, groups parts by bearing-bar spacing and gauge, and nests them onto standard 2′ and 3′ wide stock panels in 20′ and 24′ lengths to get the best yield.

  • Calculates real panel widths from bar count, spacing and gauge
  • Exports printable shear layout PDFs and CSVs for the floor
  • Includes a custom mode for one-off panel sizes
  • Python
  • Tkinter
  • openpyxl
  • ReportLab

Programming Tools Suite

DESKTOP APP

An all-in-one desktop app for a CNC programming team. It brings the tools the team reaches for every day into one window, each one built for that team's workflow.

  • Laser time calculator for quoting and scheduling
  • SigmaNEST part verifier, job setup and PDF merging tools
  • Searchable library of machine parameters, alloy codes and gauge charts
  • Rebuilt from Electron to Python and pywebview, shrinking the app from about 180 MB to tens of MB
  • Python
  • pywebview
  • JavaScript
  • HTML/CSS
  • PyInstaller

Programming Task Tracker

INTERNAL TOOL

A request and assignment tracker built into the tools suite. Engineers log programming requests by machine, material and issue, and the team assigns, details and closes them in one shared list.
